# Expense Tracker CLI

A lightweight expense tracker command-line interface to manage personal finances, track expenses, and view monthly summaries with real database backing.

Built as part of the [roadmap.sh Backend Developer Roadmap (Project 03: Expense Tracker)](https://roadmap.sh/projects/expense-tracker).

---

## Planned Features
- `expense-tracker add --description "Lunch" --amount 20`
- `expense-tracker list`
- `expense-tracker summary`
- `expense-tracker summary --month <1-12>`
- `expense-tracker delete --id <id>`
